Taxonomy Tools And Services

Version specifications 3.3

  • Graph - visualization tool to see relation of taxonomy atoms and their description
  • Structures - describe each element of taxonomy level, from attributes to parametrized atoms
  • Info - collects current versions of each part of the taxonomy tools infrastructure
  • Validation §
    - taxonomy string validation, if it is correct and not canonical it return the canonical version too
    Taxonomy string could be validate:
    • via network: using a REST-API service at the entry-point: /taxonomy/api/v1/validation/<taxonomy_string> (M in this example)
    • via shell: using commands provided by python package oq-gem-taxonomy as simple string parameter or from CSV files; currently private and available for GEM staff only: https://github.com/gem/oq-gem-taxonomy/ (until it is private and available for GEM staff only, than installing normally using pip from pypi site)
    • inside your python code: using classes provided by https://github.com/gem/oq-gem-taxonomy/ (until it is private and available for GEM staff only, than installing normally using pip from pypi site)

  • Explanation §
    - taxonomy string explanation, if it is correct and not canonical it return the canonical version too
    Taxonomy string could be explained should return different types of outputs: single line, multiple lines or json:
    • via network: using a REST-API service at the entry-point: /taxonomy/api/v1/explanation/<taxonomy_string>(with optional &fmt=<format> parameter)
    • via shell: using commands provided by python package oq-gem-taxonomy, currently private and available for GEM staff only: https://github.com/gem/oq-gem-taxonomy/ (until it is private and available for GEM staff only, than installing normally using pip from pypi site)
    • inside your python code: using classes provided by https://github.com/gem/oq-gem-taxonomy/ (until it is private and available for GEM staff only, than installing normally using pip from pypi site)

  • Python OpenQuake Gem Taxonomy §
    - python package with taxonomy classes and shell commands
    This package provide (currently) one class:
    • class GemTaxonomy
      with public methods:
      • validate(tax_string): validate a taxonomy string
      • explain(tax_string, format): explain (or translate) to different formats a taxonomy string
    and some tool:
    • gem-taxonomy-validate: validate taxonomy string passed as parameter
    • gem-taxonomy-csv-validate: validate taxonomy strings from a csv file (or a list of them) with a lot options to replace values if needed, it is used extensively for CI pipelines
    • gem-taxonomy-csv-explain: explain (or convert) taxonomy strings to different formats
    • gem-taxonomy-info: retrieves information about the taxonomy package and related packages
